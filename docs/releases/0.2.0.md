## 三种极简样式，按你的习惯调整

进入「设置 → 浮窗 → 极简进度条」，下方会出现「极简外观」。

| 样式 | 可调参数 | 开启双额度后 |
| --- | --- | --- |
| 竖条 | 高度 20–160pt、粗细 | 左侧 5 小时，右侧每周 |
| 横条 | 长度 20–160pt、粗细 | 上方 5 小时，下方每周 |
| 圆环 | 直径 20–80pt、粗细 | 外圈 5 小时，内圈每周 |

三种样式都支持 **50%–200% 整体缩放**，可以拖动滑块或输入数值。每种样式分别记忆尺寸，切换后不用重新调；恢复默认只重置当前样式。圆环粗细会按直径限制，防止双环相交。

双额度只在账号实际返回两个窗口并开启对应显示开关时出现；不会猜测或制造不存在的额度。彩色代表剩余，灰色为底轨，继续沿用绿、黄、红的缓动过渡。读取失败不会被当成 0%。

## 尺寸变了，位置和悬停逻辑保持一致

- 调节尺寸时保留组件左上角，只在触及屏幕边缘时做必要避让，并记住实际位置。
- 单额度与双额度切换不改变组件外框大小。
- 悬停继续展示完整详情，收起回到原位；展开、收起或拖动途中修改尺寸，会在当前动作结束后应用，避免中途改变动画起止形状。
- 设置窗口继续使用紧凑滚动布局，支持简体中文、繁体中文和英语。

## 同步修复：靠近屏幕底部不再顶走额度条

完整额度和极简形态通常向右下展开；下方空间不足时向上，右侧不足时向左。方向在本次开合期间保持不变，不再用展开浮层的尺寸重新挤动收起组件。内容超出可用空间时采用内部滚动；菜单栏仍在状态项下方展开。

同时保留液态胶囊动效，统一圆角裁切，避免重复遮罩产生白边或起止帧差异。
