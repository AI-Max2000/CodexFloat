## 浮窗位置不再被系统操作改写

- macOS 因分辨率、全屏、Stage Manager 或屏幕参数变化重排浮窗时，只会临时纠正显示位置，不会覆盖用户保存的锚点。
- 未手动摆放时优先跟随 Codex 标题；标题不可用时回到窗口左上角。用户拖动后改为记忆窗口相对位置。
- 完整额度与极简进度条共享同一个左上角锚点，切换形态不再产生模式间位置跳跃。
- 普通校准、唤醒和屏幕变化保留原目标窗口；明确切换或点击另一 Codex 窗口时才允许更换目标。
- Codex 横跨显示器时按工具锚点所在屏幕决定归属，不再按整个窗口面积判断。

默认只读取窗口几何。如果用户已经授予辅助功能权限，应用会先确认候选控件位于窗口顶部且是标题文本/按钮，再匹配精确的 `Codex` 标签；不会遍历读取聊天正文，也不会为了定位主动请求新权限。

## 周额度耗尽时给出明确恢复入口

仅当标准 Codex **周额度真正耗尽**，并且账号存在可确认使用的额外 Reset 时，应用才显示恢复入口：

- 完整额度、极简竖条/横条/圆环和菜单栏都提供一致反馈。
- 点击只打开 Codex「设置 → 用量」，由用户自行确认并执行手动重置。
- 系统通知可直接打开用量设置，同一耗尽周期会去重；恢复后再次耗尽才产生新一轮提醒。
- 不调用兑换接口，不自动消耗 Reset；当前客户端没有稳定的重置按钮独立锚点，因此不宣称自动滚动到具体按钮。

以下情况保持原有显示，不增加恢复入口：

- 只有 5 小时额度耗尽。
- 没有额外 Reset、Reset 已过期或可用性无法确认。
- 数据陈旧、离线、周期重置仍待确认，或账号处于支出限制状态。

剩余不足 1% 时显示 `<1%`，不会因四舍五入提前显示成真正的 `0%`。
