## 本次修复

- **上传文件时保持原位置。** 文件选择器打开后，额度条继续以原 Codex 主窗口为锚点，不跟着临时文件面板移动。主窗口短暂读不到时保留其标识；点击另一独立 Codex 主窗口仍可切换。
- **手动重置入口定位到正确标签。** 点击“去手动重置”后先打开 Codex 设置，再尝试选择“使用情况和计费”。这一步需要在 macOS 辅助功能中允许 Codex Float。缺少权限或未找到标签时会提示手动路径；重置仍由用户在 Codex 内确认，不会自动消耗次数。

## 验证说明

本地窗口跟随定向测试 19 项、窗口固定定向测试 17 项、用量恢复及语言相关测试 43 项通过；Release 警告即错误构建通过。文件选择器与设置标签的真实 Codex 界面点击仍需人工验收；相关自动化目前只覆盖隔离窗口和导航分支。GitHub CI 结果见[工作流页面](https://github.com/AI-Max2000/CodexFloat/actions/workflows/ci.yml)。
