# Codex 窗口跟随回归记录

## 行为

- 设置 → 浮窗 → 跟随 Codex 窗口移动：默认开启，仅完整额度与极简进度条显示该开关。
- 以 Codex 窗口左上角为基准保存相对位置，两种形态各自记忆。
- 拖动工具可重新固定位置；工具自身的拖动不被自动跟随抢占。
- 检测到同一 Codex 窗口的真实几何变化后，先隐藏、再更新位置；聊天内拖选但窗口未移动时不隐藏。
- 松手且位置稳定至少 120 毫秒后直接恢复，不播放追赶或滑入动画。按住鼠标中途停顿不恢复，松手后的吸附/迟到位置变化重新计时。
- 自动悬停模式下，移动时在不可见状态结束展开/收起并恢复为额度条；关闭悬停展开时保留展开状态。已有额度条与浮层的左上角锚点保持一致。
- 屏幕边缘仅临时限制可见位置，不覆盖保存的相对位置。
- 关闭开关后独立摆放；菜单栏模式不跟随。手动隐藏、前台规则隐藏、禁用和菜单栏模式停止窗口跟踪。
- 临时隐藏采用透明且不拦截鼠标的原生窗口，逻辑显示状态不变；恢复不调用 show、不触发额度刷新、不修改显示偏好。手动/前台隐藏先移出屏幕显示，再停止跟踪，防止清理回调闪现浮窗。
- 移动时目标不可用则保持隐藏，暂停临时检查时钟，仅低频等待可用目标；有效目标返回并稳定后恢复。
- 第一次拖动与松开同步采样，检测到运动后暂停显示器逐帧回调。临时 30 Hz 检查时钟不依赖窗口可见性，负责隐藏时定位与松手恢复；结束后销毁。
- 拖动期间锁定目标窗口，只查询它的几何信息；全窗口发现留到静止后。静止时保留 4 Hz 维护、最多每秒一次窗口发现，不持续逐帧工作。

## 自动验证

移动隐藏版本的普通全量回归与 Address Sanitizer 全量回归均为 **148 项通过**。
`WindowPinTests.swift` 的位置与动效回归覆盖：

- 默认开启、关闭后的持久化、切换形态不改写偏好。
- 窗口平移与尺寸变化时，三种画布尺寸的左上角偏移一致。
- 负坐标、不同屏幕高度、屏幕边缘限制与回到原位置。
- 两种形态的相对位置独立保存、重新读取及损坏数据回退。
- 无窗口标题也可解析几何信息；过滤其他进程、隐藏窗口、小窗口和非普通窗口层。
- 原生完整/极简浮窗在展开、收起中移动，结束帧不跳回；暂停后恢复，关闭后不移动。
- 拖动极简条重设偏移、开关切换、菜单栏排除，以及切回极简后恢复相对位置。

这些测试使用隔离偏好、临时数据库和窗口几何样本，不启动真实账号额度读取。
既有的双额度显示、三语言、原生菜单栏、动画与高度自适应测试同时通过。

调度与移动隐藏验证：

- 第一条拖动与松开事件不经过等待或队列即可交付位置。
- 模拟 60/120 Hz 回调与 2 毫秒查询耗时，确认隐藏后停止逐帧查询，使用独立低频时钟定位。
- 持续拖动及其间的激活/屏幕变化请求不会触发全窗口扫描。
- 重复鼠标事件被限流，松开时强制读取最终位置。
- 在内容区拖拽而窗口未动时，不猜测或伪造位移。
- 按住鼠标但停止移动时保持隐藏；释放后等待稳定时段，迟到位置变化会重置时段。
- 漏掉松手事件仍能恢复；系统移动没有鼠标事件也能根据几何变化隐藏并恢复。
- 目标消失时不显示旧位置，替代目标需要稳定后才能恢复。
- 目标消失后的退避、重新发现，以及停止后资源清理、旧回调无效。
- 真实 `CADisplayLink` 在测试进程自有的原生窗口中产生回调，暂停/停止后不再回调。
- 真实原生窗口 alpha 为 0 时独立检查时钟仍产生回调，结束/停止后不再回调。
- 自有原生测试窗口通过生产用的窗口几何查询接口连续移动至少 48 次，验证隐藏期间每次应用后的相对偏移一致，持有拖动阶段不做窗口发现；模拟释放并停稳后恢复透明度和鼠标交互。
- 两种形态的原生窗口：隐藏先于移位、不可见时点击穿透、展开过程中隐藏后安全收起、恢复不产生逻辑显示事件也不写位置偏好。
- 手动隐藏期间结束移动不重新显示；关闭跟随/切到菜单栏清除临时透明和点击穿透状态。
- 停止并重新启动跟踪后，旧的显示/鼠标/维护/检查回调全部失效。

原生测试会输出查询和应用位置的耗时；这些数值不包含完整的系统呈现延迟，且受测试进程负载影响，不能当作真实 Codex 拖动延迟或实际帧率。首次创建的测试窗口尚未被 WindowServer 注册时，允许发现重试；开始连续采样后不允许额外发现。

GitHub macOS 虚拟机首次回归在固定 3 秒内收到 42 个变化样本，未满足 48 个样本的旧等待条件。现改为最多 8 秒的有界条件等待，仍要求全部 48 个样本和位置/显隐/资源清理断言通过，不把虚拟机时钟调度速度作为帧率门槛。

## 尚需人工验收

当前自动化工具禁止控制 Codex 主应用，故没有将“实际拖动 Codex 窗口”记为已验证。
负坐标/跨屏断言是几何测试，不等同于实体多显示器和不同刷新率实测。

- 在完整/极简形态中慢速及快速拖动 Codex，确认检测到移动后消失、释放停稳后在原相对位置恢复。
- 按住鼠标暂停、继续拖动、拖选聊天文字、系统窗口吸附，确认不闪现、不误隐藏。
- 将工具拖到新位置，停顿后继续拖动；重启助手后检查相对位置。
- 从展开/收起动画中开始拖动 Codex，确认隐藏后恢复时无白边和旧坐标回跳。
- 关闭开关后移动 Codex，确认工具不移动；菜单栏模式保持系统位置。
- 实体跨屏、全屏与退出全屏、最小化/恢复、多个 Codex 窗口切换。
- 长时间空闲和连续拖动的 CPU/内存采样尚未作为本次实测指标发布。
