# 极简样式与自定义尺寸回归

日期：2026-09-03。适用于 0.2.0 预览版源码；下载与发布信息见 [0.2.0 更新说明](releases/0.2.0.md)。

## 使用方式

在「设置 → 浮窗」选择「极简进度条」，再到下方「极简外观」调节：

- 竖条：高度 20–160pt。
- 横条：长度 20–160pt。
- 圆环：直径 20–80pt；双额度外环为 5 小时、内环为每周。
- 粗细：线形 2–12pt；圆环按直径限制为 2–10pt，以免双环相交。
- 整体大小：50%–200%；每种样式分别保存参数，恢复默认只重置当前样式。

数值为 macOS 逻辑点，不是物理像素。最小交互画布为 36×36pt，周围留有透明拖动区域。尺寸预览过大时等比缩小，但实际悬浮组件仍采用用户选择的尺寸。不开启双额度时只显示当前标准额度窗口，不制造第二个额度。

## 人工验收边界

自动测试使用自有原生测试窗口和可控几何，不等同于已完成所有实体多显示器、全屏 Spaces、VoiceOver 或不同刷新率显示器的真人验收。正式公开版本仍需这些硬件 / 辅助功能场景复核。

建议人工回归：分别选择三种样式，拖动到四角，尝试最小 / 最大尺寸；在开合中快速更改设置；关闭并重开；移动 Codex 窗口；检查单双额度、亮暗模式及三种语言的设置布局。
