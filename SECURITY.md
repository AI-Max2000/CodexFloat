# Security Policy

## Supported versions

Until the first stable release, only the latest published version is supported.

## Reporting a vulnerability

Please use the repository's **Security → Report a vulnerability** form. Do not open a public issue for credential exposure, local data disclosure, code execution, or update-signing problems.

Include the Codex Float version, macOS version, reproduction steps, and impact. Never attach `auth.json`, Codex databases, rollout files, browser data, task content, or unredacted diagnostics.

The project will acknowledge a complete report when maintainer availability permits. No fixed response SLA is promised for this independent project.
